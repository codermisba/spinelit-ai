Spine MRI — localization, segmentation & DDD API

Upload a midsagittal T2 lumbar MRI. The API returns detected vertebra/disc blocks, a U-Net segmentation overlay, per-level Pfirrmann grades and a validated report. The gallery below shows real held-out segmentation outputs from the trained model. Research prototype — not a medical device.
